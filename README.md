В терраформовском гитигноре будут игнорироваться файлы и директории по разным правилам. Если в гитигноре указан символ *, то это означает, что на его месте может быть любое количество других символов. Добавление такого символа к определённому буквосочетанию позволит игнорировать любые файлы с этим буквосочетанием.
Однако, если запись не содержит символа *, а содержит только обычные буквы, например файл crash.log, то проигнорируется только этот файл. Файлы вроде 2crash.log или crash.log234 игнорироваться не будут.

Краткое описание логики терраформовского гитигнора:

---

Гит проигнорирует конкретные файлы:
crash.log
.terraform.tfstate.lock.info
.terraformrc
terraform.rc
override.tf
override.tf.json

---

Гит проигнорирует все файлы по шаблону, т.к. есть подстановочный символ:
*.tfstate
*.tfstate.*
*.tfvars
*.tfvars.json
*_override.tf
*_override.tf.json
crash.*.log

То есть любые файлы, в которых будет наличие вышеуказанных буквосочетаний. Например: 12312.tfstate 2eew.tfstate 6666.tfstate hello.tfstate и т.п.

---

Гит проигнорирует всю директорию целиком и включённые в неё файлы:
.terraform/
